# Cyly

[English](README_en.md)

Cyly 是一门静态类型、原生编译的编程语言。它保留 C 对内存布局和运行成本的直接控制，同时引入一般联合类型、单文件模块、继承与异常等能力；这些能力不依赖隐式堆分配、运行时对象头或自动资源管理。

Cyly 更在意程序实际做了什么，而不是语法表面隐藏了多少细节。值何时复制、内存由谁释放、方法调用绑定到哪个函数、联合值按哪种类型读取，都有明确规则。编译器尽量在编译期完成工作，作者保留对运行时行为的直接控制。

## 核心设计

- **值语义与可预测布局**：类对象和定长数组在赋值与按值传参时复制值；对象只包含字段与对齐填充，定长数组不隐式退化为指针。
- **显式内存与指针**：不内建 GC、ARC 或 RAII，不产生隐式堆分配。裸指针操作无需 `unsafe`，内存寿命、边界和指针有效性由作者负责。
- **内联联合与比特重解释**：联合值采用类型标签与内联存储槽，不进行隐式堆装箱；`typeof` 查询当前成员，`.as()` 按目标类型显式读取，编译器不采用基于类型的严格别名假设。
- **静态分派与显式多态**：继承和方法重写按接收者的静态类型绑定，不包含隐式虚表指针；运行期多态通过联合类型或显式函数指针表达。
- **精简语言核心**：连续内存视图、动态数组、Arena 和引用计数容器由库实现；内建 `string` 是独立的只读字节视图。
- **单文件模块与原生工具链**：跨模块引用需要显式导入，导入不向第三方传递；编译经 LLVM IR 生成标准目标文件，并交由系统工具链完成链接。

## 当前状态

前期语言设计已完成，完整编译器实现尚未开始。仓库中已有的早期前端代码仅用于探索和验证，不代表可用的语言实现。

## 设计文档

[语言规范草案](docs/language-spec.typ) 是语言语义、语法和运行时规则的权威记录。早期的 [设计决策](old/DESIGN_DECISIONS.md) 已归档，仅供追溯；与规范不一致时以规范为准。

规范沿用设计决策的章节顺序，展开 EBNF、静态约束、运行语义、诊断与示例，并区分已定规则、候选补充和实现约定。使用 Typst 运行 `make docs` 可生成 [PDF](output/pdf/cyly-language-spec.pdf)；需要可用的中文字体，详见规范末尾的构建说明。

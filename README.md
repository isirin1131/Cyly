# Cyly

[English](README_en.md)

Cyly 是一门以 “Yet Another A Better C” 为方向的编程语言，关注静态类型、原生编译、显式内存管理和可预测的运行时成本。

它的核心原则是：高级特性的运行时成本尽量接近手写同等功能的 C；未使用的特性不增加运行时成本。

## 核心设计

- **明确的值语义**：结构体、类和定长数组在赋值与按值传参时复制值；定长数组不隐式退化为指针。
- **显式内存与指针**：不内建 GC、ARC 或 RAII，不产生隐式堆分配；裸指针操作无需 `unsafe`，内存寿命、边界和指针有效性由作者负责。
- **内联联合类型**：联合值采用类型标签与内联存储槽，不进行隐式堆装箱；通过 `typeof` 查询当前成员，通过 `.as()` 显式读取，不做隐式类型收窄。
- **编译期静态分派**：类与结构体的继承和方法重写按接收者的静态类型绑定，不包含隐式虚表指针或运行时对象头。
- **精简语言核心**：连续内存视图、动态数组和动态资源管理由库实现；内建 `string` 是独立的只读字节视图。
- **单文件模块与原生工具链**：每个源文件构成一个模块，跨模块引用需要显式导入；编译经 LLVM IR 生成标准目标文件，并交由系统工具链完成链接。

## 当前状态

前期语言设计已完成，完整编译器实现尚未开始。仓库中已有的早期前端代码仅用于探索和验证，不代表可用的语言实现；示例也以阐明目标设计为主。

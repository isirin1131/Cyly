# Cyly 规范审阅待办

下文按规范章节标注问题。语言规则以[规范正文](language-spec.typ)为准。

## 附录 B 列出的待补项

- **跨文件的递归结构（§3.4、§9.1、§13.2）**　按 §3.4 经显式指针递归的草案，分别位于两个文件的结构如何相互引用？当静态库或动态库与调用方各自声明等价的递归结构时，独立编译双方怎样识别同一类型？
- **多模块程序的初始化（§9.1–9.2、§13.2）**　模块变量由程序员显式给出初值。像 `i32 port = read_port();` 这样的模块声明是否允许？若允许，分别编译的源文件组成可执行程序、链接静态库或加载动态库时，谁触发求值，各模块何时可以读取彼此的变量，初始化依赖成环时如何处理？
- **联合的 ABI 表示（§4.2、§13.2）**　独立编译双方如何为同一联合确定成员到标签的映射、标签宽度和存储槽布局？例如，库按 `i32 | f32` 返回值，调用方按 `f32 | i32` 接收，两侧必须对当前成员作出相同解释。
- **文法、作用域与基础运算（§2、§3、§7）**　补全数字和注释的词法、对象类型文字 `ObjectType` 的产生式、各类声明的作用域与可见范围，以及基础运算的操作数和结果类型。
- **标量的打印格式（§6、§8.4）**　实现文档还需记录整数、浮点、布尔、字符串和指针的具体输出形式，例如浮点精度和指针地址的格式。可打印的类型和末尾追加的换行已有规定。

## 正文中仍影响程序的问题

### 类型、字面量与运算

- **嵌套数值表达式的定型（§3.2，留待细化）**　在 `i64 y = (1 + 2) * 3;` 中，外层期望类型如何传入内层加法？
- **字面量类型（§3.1–3.2、§4.1、§11.3）**　`LiteralType` 支持的字面量种类还需给出完整范围。字面量类型作为独立变量或联合成员时，如何确定其存储表示？
- **常量表达式（§3.3、§5.3、§7.3.3）**　元素或字段全为常量的数组字面量、结构对象字面量本身是否属于 `ConstExpr`？对于常量诊断，若模块变量 `d` 初始为零，在函数内赋成非零后执行 `10 / d`，此处按运行期读取还是按初值触发常量除零诊断？

### 作用域、模块与控制流

- **返回路径的静态判定（§8.2、§10.2，开放问题，暂缓细化）**　首版以常规控制流检查为目标，不要求超出现有主流语言常规返回检查的条件关系推理。连续的 `if (b) return 1; if (not b) return 2;` 是否通过，以及循环和具名 `break` 的具体可达性判定，留待实现时细化；尚未采纳额外的局部布尔事实传播要求。
- **异常传播到入口（§9.3、§12.1–12.3）**　若 `main` 抛出的值一路都没有匹配的 `catch`，程序如何结束？正文规定了匹配、展开与显式清理，仍需给出传播到最外层时的行为。

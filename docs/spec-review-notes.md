# Cyly 规范审阅待办

下文按规范章节标注问题。语言规则以[规范正文](language-spec.typ)为准。

## 附录 B 列出的待补项

- **函数指针返回类型的边界（§3.1、§10.1）**　无括号的 `*func(i32) -> i32 | null` 如何解析？`(*func(i32) -> i32) | null` 的值可以是函数指针或 `null`。`*func(i32) -> (i32 | null)` 的值是函数指针，调用结果可以是 `i32` 或 `null`。
- **联合成员的顺序与类型身份（§3.1、§12.2）**　展开别名、展平直接成员并去重后，`i32 | f32` 与 `f32 | i32` 是否为同一类型？这决定了跨模块传值是否类型匹配，也决定了抛出前一种静态类型的值时，后一种类型的 `catch` 能否精确匹配。
- **联合标签与跨库传值（§4.2、§13.2）**　在多文件分别编译、静态库链接、调用动态库时，哪些产物之间可以交换联合值？在支持的边界上，双方如何约定标签编码、宽度和存储槽布局，使同一成员在两侧都能正确写入、读取和比较？跨联合的 `typeof(a) == typeof(b)` 已按当前成员的类型身份定义，具体编号方式仍待确定。
- **文法、作用域与基础运算（§2、§3、§7）**　补全数字和注释的词法、对象类型文字 `ObjectType` 的产生式、各类声明的作用域与可见范围，以及基础运算的操作数和结果类型。例如，两个指针值能否用 `==` 比较，允许哪些指针类型组合？
- **普通函数取指针（§10.1）**　已有模块级函数 `f` 时，怎样把它存入签名相符的函数指针变量？类方法已有 `&Circle.area` 的写法，普通函数的取值语法仍缺。
- **标量的打印格式（§6、§8.4）**　实现文档还需记录整数、浮点、布尔、字符串和指针的具体输出形式，例如浮点精度和指针地址的格式。可打印的类型和末尾追加的换行已有规定。

## 正文中仍影响程序的问题

### 类型、字面量与运算

- **字面量的定型（§2.2、§3.2）**　在 `i8 x = -128;` 中，若按草案把负号解析成一元运算，是在哪一步对 `i8` 做范围检查？在 `i64 y = 1 + 2;` 中，声明的期望类型是否传给两个操作数？
- **字面量类型（§3.1、§4.1、§11.3）**　`LiteralType` 允许哪些字面量？例如 `"user" | "order"` 如何接收值 `"user"`，数值字面量类型 `200` 如何确定其整数类型和表示？这也决定了如何检查正文已有的字段收窄声明。
- **常量表达式（§3.3、§5.3、§7.3.2、§9.2）**　元素或字段全为常量的数组字面量、结构对象字面量能否初始化模块变量？对于常量诊断，若模块变量 `d` 初始为零，在函数内赋成非零后执行 `10 / d`，此处按运行期读取还是按初值触发常量除零诊断？
- **递归别名（§3.1、§3.4）**　`typedef` 的定义能否经指针引用自身？这样的结构可以具有有限尺寸，但判断结构兼容时仍会再次遇到同一别名。别名若直接或间接形成无法展开的环，应在哪里报错？
- **整数运算与显式转换（§7.3）**　有符号最小值对 `-1` 取余得到零，还是与除法的商溢出一样触发 Trap？移位量为负或大于等于位宽时结果如何，有符号数右移如何填充高位？显式转换还缺少整数窄化、浮点舍入、浮点值超界或为 NaN 时转整数，以及指针与不同宽度整数互转的结果规则。
- **跨成员读取布尔值（§4.3）**　将值为 `2` 的 `u8` 存入 `u8 | bool`，再把 `.as(bool)` 用作 `if` 条件，如何从槽内字节得到真假？§4.3 已允许这次读取。

### 类与调用

- **收窄为子集联合的继承字段（§4.1–4.3、§5.1、§11.3）**　例如父字段是 `i32 | f32 | string`，子类把它收窄为 `i32 | f32`。将子字段复制给独立的窄联合变量、再将窄联合写回字段时，如何在两种布局间读写并维护父槽标签？若取 `&child.field` 传给接收窄联合指针的函数，能否直接读写原地的父槽？
- **成员名与父类方法调用（§11.1、§11.4–11.5）**　字段与方法（含继承成员）能否同名？若字段存放函数指针，答案决定 `obj.f(x)` 绑定到谁。另需明确调用无额外参数的父类方法时，`super.f()` 是否已传入当前接收者。
- **省略初始化参数（§10.1、§11.6）**　`init` 中带默认值的参数能否排在必填参数之前？按位置调用 `ClassName.init(...)` 或 `super.init(...)` 时，哪些实参可以省略？

### 作用域、模块与控制流

- **块内的类型声明（§3.5、§8.1）**　能否在块内写 `typedef`？§8.1 将现有的 `BlockItem` 标为草案，并明确留下了这个问题。
- **循环导入（§9.1–9.2）**　两个模块的函数仅互相引用、没有初始化依赖时，能否互相导入？如果可以，需说明如何诊断跨模块的常量初始化依赖环。
- **返回路径的静态判定（§8.2、§10.2）**　有返回值的函数若以 `if (b) return 1; if (not b) return 2;` 结束，编译器是否必须识别两种布尔值均已覆盖？判定规则还需说明如何处理循环及具名 `break` 能到达的出口。同一段程序能否通过编译取决于这个边界。
- **异常传播到入口（§9.3、§12.1–12.3）**　若 `main` 抛出的值一路都没有匹配的 `catch`，程序如何结束？正文规定了匹配、展开与显式清理，仍需给出传播到最外层时的行为。
